## 📋 2. 実装済みコアモジュールと機能仕様

### 1. コントローラー管理と 3系統並行入力ブリッジ (Gamepad Management & Tri-Input Bridge)

- [x] **1.1 自動スキャンとホットプラグ検出 (Hotplug Detection)**：
  - アプリ起動時に `gilrs` を介して接続中のコントローラーを自動認識。
  - ケーブル抜差や Bluetooth 再接続イベントをリアルタイムに検知して一覧を更新。
- [x] **1.2 各種コントローラー対応と入力の正規化**：
  - 8BitDo Micro (Dモード / Sモード)、Joy-Con (L / R / 2本持ち)、Switch Pro コントローラー等に対応。
  - OS やメーカーによるボタン配置・スティック数値の差異をバックエンドで自動正規化。
- [x] **1.3 ペアリングガイドとシステム設定ショートカット**：
  - 8BitDo Micro および Joy-Con のモード切替・ペアリング手順を図解で案内。
  - macOS の Bluetooth 設定画面をワンクリックで開くボタンを配置。
- [x] **1.4 3系統入力マージアルゴリズム (Tri-Input Bridge)**：
  - **物理コントローラー**：`gilrs` による高速ポーリング（遅延 < 1ms）。
  - **PC キーボード**：デフォルト WASD によるスティック移動シミュレーション、8方向キーの競合自動解消。
  - **画面タッチ / マウス**：120Hz 直接 DOM Transform、Pointer Capture、スプリング物理アニメーション（`useStickDrag`）、最低 140ms パルス保証（`usePulsedButtonPress`）。
  - **状態マージ (`gamepad.rs`)**：デジタルボタンは論理和（OR）、方向キーやスティック入力時は仮想入力を優先。誤操作防止用のワンクリックミュート（Mute）モードを搭載。
- [x] **1.5 ゴーストビジュアライザー & ミニ HUD モード**：
  - ゴースト型コントローラー。メタモンのような表情変化とスティック角度のリアルタイム描画。
  - レスポンシブ等比スケーリング（Auto Scale-to-Fit）。画面サイズ縮小時（< 720x460）は自動的に極小 HUD ウィンドウへ移行。

### 2. リアルタイムタイムラインストリーム (Live Timeline Stream)

- [x] **2.1 逆太鼓 / DAW 風 5 トラック楽譜キャンバス**：
  - アクションボタン (ABXY)、十字キー (D-Pad)、スティック (L3/R3含む)、ショルダーボタン (L/R/ZL/ZR)、システムボタン (Minus/Plus/Home/Capture)。
- [x] **2.2 長押し光帯のリアルタイム描画とグリッド表示**：
  - ボタン長押し時に動的な光帯を描画し、離した瞬間にノーツの長さを確定。
  - 10秒 / 15秒 / 30秒 / 60秒の速度切り替え、5秒 / 1秒のタイムグリッド線に対応。
- [x] **2.3 高パフォーマンス描画**：
  - Retina ディスプレイ向けに `devicePixelRatio` スケーリングを適用し、鮮明な線画を実現。
  - 端部のグラデーションフェードアウト処理、画面内の有効アクション数の動的集計。

### 3. ESP32 ハードウェア管理とファームウェア書き込み (Sequential Hardware Management)

- [x] **3.1 シリアルポート自動列挙とチップ認識**：
  - 利用可能なポートを自動検出し、CH340 / CP2102 / FTDI 等のチップを優先識別。
  - macOS の Bluetooth 仮想シリアルポートや重複した tty デバイスを自動フィルタリング。
- [x] **3.2 60Hz ハートビート通信と 3 段階ハンドシェイク**：
  - 19200 ボーレートで接続し、`0xFF` ➔ `0x33` ➔ `0xCC` の 3 段階ハンドシェイクを実行、`0x90` ACK を確認。
  - バックグラウンドスレッドで 60Hz のハートビートパケットを常時送信。ESP32 側は 200ms タイムアウトで自動保護。
- [x] **3.3 Switch ペアリングとクイック復帰**：
  - Switch の「持ちかた / 順番をかえる」画面向けの L+R ペアリングガイド。
  - ペアリング情報を記憶し、A ボタン / Home ボタンでワンタッチ復帰・再接続。
  - 別の Switch に繋ぎ変えるための「ペアリング情報消去 (Clear Bonds)」コマンドを装備。
  - 接続解除時には安全のため中立パケット（Safe Disconnect）を自動送信。
- [x] **3.4 ワンクリックファームウェア書き込み (Firmware Flasher)**：
  - プロジェクト同梱の結合バイナリ `firmware/PRO-UART0.bin`（書き込み開始番地 `0x0`）を内蔵。
  - ユーザー独自の `.bin` ファイル選択にも対応。
  - 460800 ボーレートの高速書き込み、ターミナルログおよび進行度パーセント表示、書き込み後の自動再起動。

### 4. マクロスタジオ - リアルタイム差分レコーダー (Macro Studio - Delta Recorder)

- [x] **4.1 3-2-1 カウントダウン待機 (Countdown Overlay)**：
  - 録画開始時に画面全体へ 3-2-1 カウントダウンを表示し、コントローラーやキーボードの準備時間を確保。
- [x] **4.2 ミリ秒精度の差分キャプチャアルゴリズム (`useMacroRecorder.ts`)**：
  - デジタルボタン：押下開始時刻を記憶し、離した瞬間に継続時間 (`durationMs`) と次ステップまでの待機時間 (`delayAfterMs`) を正確に算出。
  - アナログスティック：デッドゾーン (`STICK_DEADZONE = 25`) を超えた時点で計測を開始し、中央に戻った際に 1 ステップとして記録。
  - 十字キー：ニュートラル (`8`) から変化した時点で方向と継続時間を記録。
- [x] **4.3 レコーディング UI とステップ数表示**：
  - 録画中に点滅する赤いインジケーター、経過時間、記録済みアクション数をリアルタイム表示。
- [x] **4.4 マクロ保存ダイアログ (`SaveMacroModal.tsx`)**：
  - 録画終了時にダイアログが開き、マクロ名、説明、タグ（例: `#ポケモン`、`#あつ森`、`#連打`）を設定可能。

### 5. マクロタイムラインエディターとループ再生エンジン (Macro Editor & Playback Engine)

- [x] **5.1 マルチトラック楽譜タイムラインとステップ一覧 (`MacroScoreSheet.tsx`, `MacroStepList.tsx`)**：
  - 5 トラック構成の DAW 風ブロック表示。
  - 各アクションの継続時間 (`durationMs`) や待機時間 (`delayAfterMs`) を直接クリックして数値編集。
  - ドラッグ＆ドロップによる並び替え、ステップの上下移動、複製、削除、無駄な待機時間のワンクリックトリミング。
- [x] **5.2 マクロライブラリと永続化 (`macroStorage.ts`)**：
  - プリセットマクロ：ポケモン自動孵化（ぐるぐる回転）、あつ森流れ星祈願（Aボタン連打）、ゼルダの伝説弓集中（バレットタイム照準）。
  - ブラウザの `localStorage` への自動保存、タグによる絞り込み・検索に対応。
- [x] **5.3 ファイルのインポート/エクスポートと完全バックアップ**：
  - 単一マクロの `.json` ファイル書き出し・読み込み。
  - ライブラリ全体のワンクリック一括バックアップ (`ghostpad_macros_backup_*.json`)。
  - JSON ファイルのドラッグ＆ドロップ登録、データ構造の自動検証と自動修復。
- [x] **5.4 ループ再生と速度変更 (`useMacroPlayer.ts`)**：
  - 3 種類の再生ループ：1 回再生、指定 N 回ループ（2〜999 回）、無限ループ（∞）。
  - 4 段階の再生速度変更：0.5x、1.0x、1.5x、2.0x。
  - 太鼓風リアルタイム再生ストリームで、現在実行中のアクションカードとループ回数をハイライト。
- [x] **5.5 緊急停止・キー固定保護 (Emergency Fail-Safe)**：
  - キーボードの `Esc` キー押下または UI の「緊急停止」ボタンにより、待機タイマーを即座に破棄。
  - バックエンドの `reset_virtual_inputs` を呼び出して完全中立パケットを送信し、ボタンの押しっぱなし状態を防止。
